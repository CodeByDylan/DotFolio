## assembled

Elk project leest zijn eigen repository. Een `.folio`-map naast de code beschrijft het project, en
deze site stelt samen wat hij vindt — je leest dus wat die repository vandaag over zichzelf zegt.

## stack

C# en .NET aan de achterkant, met TypeScript en React aan de voorkant. Het meeste is open source, en
de projecten hier zijn de eerlijke versie van waar ik mee werk.

## availability

Ik neem geselecteerd werk aan. Het snelst bereik je me via de links in de navigatie.
